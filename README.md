# Lab3DT208G

Detta project skapades genom att använda [Angular CLI](https://github.com/angular/angular-cli) version 21.2.7.


Webbplatsen som skapats heter Mat- och bakbloggen. Det är en sida som presenterar recept inom matlagning samt bakning (fiktiv webbplats). Webbplatsen är uppbyggd med olika
komponenter. Home, calculator och about är huvudsidorna (Routes), medan mainheader samt mainfooter infogas på samtliga sidor. 
- Home, sidan där alla recept presenteras (startsidan).
- Kalkylatorer, sidan med de tre olika kalkylatorerna (mått, längd och temperatur). Dessa är skapade med tvåvägs-databindning.
För input fält används template-driven forms och därmed import av FormsModul.
- Om oss, sidan som innehåller presentation av sidan samt tankar och information om uppgiften.

CSS är uppdelad i flera filer, där varje komponent har sin egen CSS och utöver det finns även en huvudfil för global CSS. 

Bilderna på webbplatsen är hämtade från pexels.com.
